## 六、免费功能与付费功能

### 6.1 免费功能

本应用的基础功能可免费使用，无需注册或登录。免费用户可使用：

1. **词库学习**：浏览并使用本应用提供的全部词库，所有词库均免费，不存在需要单独购买的词库；
2. **挑战模式**：同时最多创建并保留 **1 个**挑战任务，挑战的关卡数量不限，可完整挑战整个词库；
3. **漫游模式**：每个词库可漫游前 **100 个**单词；
4. **生词本**：最多保存 **50 个**单词，可查看、排序和删除生词；
5. **数据同步**：开启 iCloud 后可在同一 Apple ID 的设备间同步生词本、挑战任务与漫游进度。

说明：生词本挑战为一次性练习，退出后不会保存在挑战列表中，也不占用上述挑战任务数量。

### 6.2 付费功能（高级版）

本应用提供**一次性买断**的高级版（应用内购买，非消耗型商品），购买后永久解锁，不涉及订阅、不自动续费、不会周期性扣费。高级版包含：

1. **挑战任务不限数量**：可同时创建任意多个挑战任务；
2. **生词本不限单词数**：可保存任意数量的生词；
3. **漫游不限单词数**：可漫游每个词库的全部单词；
4. **导出生词本**：支持将生词本导出为 txt 或 CSV 文件；
5. 高级版权益适用于同一 Apple ID 下的所有设备。
